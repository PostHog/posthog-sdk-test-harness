Add the opt-in `feature_flags_known_absent` suite for adapters that declare both `feature_flags_local_evaluation_v1` and `feature_flags_known_absent_v1`. `/get_feature_flag` gains optional `person_property_keys_known_absent`, `group_property_keys_known_absent` and `allow_remote_fallback` params, sent only when a test sets them. `allow_remote_fallback: true` selects the SDK's default local-then-`/flags` getter. The suite checks local results for listed keys (`is_not_set`, `is_set`, a listed key overriding a supplied value, an operator table, and a 1001-key list) with no `/flags` request, resolves a listed group key locally through the default getter, falls back to `/flags` for a group key listed under another group type and for an unlisted omitted key, and checks the `/flags` fallback body carries the listed keys, and checks that a field is omitted or null when nothing is listed for it, including when the caller passes an empty list or map. Adds the `assert_flags_request_field_absent` assertion.
